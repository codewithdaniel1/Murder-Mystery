Original 1k glTF assets bundled to GLB. Tree geometry simplified offline with meshoptimizer, retaining UVs, normals and original material maps. Model meshes are instanced in the game to reuse geometry and textures.

## Additional garden tree

- `garden-tree.glb`: [Tree Small 02](https://polyhaven.com/a/tree_small_02), Poly Haven, [CC0](https://polyhaven.com/license). Species unspecified; selected for an upright leafy silhouette. Original model and maps downloaded from the Poly Haven public asset API on November 12, 2026. Geometry simplified with meshoptimizer to 57,997 triangles (three materials), 512px bark/branch maps and 1024px leaf color/opacity. The original separate leaf alpha map is embedded into the color texture and used with alpha masking, not opaque leaf rectangles. File size: 4,967,876 bytes.
